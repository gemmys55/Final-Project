<p><h3>Objective </h3>
  To analyze and predict injury and poprate (Population Rate of Incidents) based on transport mode, severity, and population data.

<h2>Conclusion

“In this project, I developed a machine learning model to analyze and predict road traffic injuries using a structured data-driven approach.
I performed data preprocessing techniques such as handling missing values, removing outliers, and transforming skewed data to improve data quality.
Multiple machine learning models were implemented and evaluated using performance metrics like R² score and RMSE.
Among them, the best-performing model was able to accurately capture patterns in the data and provide reliable predictions.
Overall, this project demonstrates how machine learning can be effectively used to identify key factors influencing road traffic injuries and support data-driven decision-making for improving road safety.”</h2>
